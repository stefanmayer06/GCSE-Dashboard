# GCSE Dashboard

This repository contains the website/API and the full cross-platform mobile app:

- `website/` contains the GCSE Study Desk website, API, database configuration, tests, and deployment files. Run website commands from that directory.
- `app/` contains the Expo/React Native iOS and Android app, tests, EAS profiles, and marketplace release drafts. Run app commands from that directory.

See [`website/README.md`](website/README.md) and [`app/README.md`](app/README.md) for setup, development, deployment and release instructions.

From `website/`, use `npm run dev`, `npm run build:vercel`, and the documented test commands. From `app/`, use `npm start`, `npm run ios`, `npm run android`, `npm run lint`, `npm run typecheck`, and `npm test`.
