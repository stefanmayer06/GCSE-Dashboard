# V3 research notes (Sept 2026)

## Competitors studied

| Product | Does exceptionally well | Friction / gap V3 exploits |
|---|---|---|
| Seneca | Free breadth (600+ courses), daily habit, retrieval + spacing, school footprint (96% secondaries, ~14M students) | Text-heavy, thin video, breadth-over-depth; repetitive Q formats; XP/streak grind over understanding |
| Cognito | Short animated videos, exam-mapped notes, cheat sheets, quizzes + flashcards + past papers in one place; bite-size fits lunch-break revision | Weekly caps; narrower subject depth than libraries; still content-led, weak mistake-to-mastery trail |
| Save My Exams | Examiner-written notes, deep topic-question + past-paper library, strong search intent capture | Paid library, not a guided plan-to-mastery loop |
| Maths Genie / Corbettmaths / PMT | Free, trusted, past/predicted papers, 5-a-day habit | Fragmented PDFs, no account loop, no marking trail, Maths-only |
| BBC Bitesize / Oak | Trusted, video-rich, free, no paywall | No adaptive plan, no timed-session management, no personal retry |
| Brilliant | Learning by doing, interactive visuals, progression, rewarding actions, difficult ideas made approachable | Not GCSE/AQA; V3 borrows: manipulatives where they teach, micro-interactions, exploration before explanation |
| Duolingo / Memrise | Engagement loops, short sessions, delightful animation, personality, achievement | Punishment-heavy streaks, XP grinding vs learning, no clear goal ("finished tree, can't converse"); V3: kind streaks, freezes, weekly goal, mastery over XP |
| Khan / Coursera / Udemy | Course discovery, lesson structure, pathways, completion, certificates | Course-viewing, not exam-trail; V3 borrows: clear pathways, completion evidence |
| Notion / Linear / Arc / Spotify / Headspace | Calm command surfaces, ⌘K, tasteful motion, focus modes, streaks without shame | Non-education; V3 borrows: ⌘K palette, calm density, intentional motion |

Principle extracted: **breadth is won; the trail is open.** Nobody owns
`exam date → diagnostic → mission → timed attempt → marking → reason →
retry → mastery` as one visible product. V3 makes that the hero.

## User sentiment (web + forums, Sept 2026)

- "Seneca good for quick recap/overview, then immediately past-paper questions
  to consolidate" (The Student Room). → V3 order: overview → micro-practice →
  timed paper, linked in one flow.
- "Bored flipping guides, hard to concentrate; GIFs/video/interactive keeps
  me engaged whilst I master knowledge" (Seneca blog comments, Cognito
  testimonials: short videos, not too long, clearer explanations).
  → V3: bite-size lessons, worked methods, visual stimuli, no walls of text.
- "Streaks and XP are counterproductive … grind timed challenges for XP rather
  than learn; fear of losing streak brings you back for one tiny lesson"
  (r/duolingo, heavily up-voted). "Streak punishment after 3 missed days",
  "500-day streak became overwhelming", "1080-day streak, gave it up after
  leagues/challenges piled on". → V3: freezes banked and visible, rest days,
  "paused not broken", weekly goal of 3 missions, no leagues, celebrate
  mastery/personal-best not grind.
- "Finished the whole tree and couldn't hold a basic conversation; no clear
  goal, autopilot 5-min sessions treated same as real study" → V3: readiness
  is evidence-gated ("Building" until enough marked work), every stat has a
  decision attached ("do this first", "retry these 3").
- Overwhelming dashboards, confusing nav, meaningless metrics (mission brief +
  consistent forum complaints) → V3: one hero next-step, 4 stats max each with
  a "so what", progressive disclosure, grouped nav, ⌘K for power users.
- Accessibility threads: contrast, keyboard, focus, dyslexia-friendly reading,
  colour-blindness, reduced motion → V3: AA pairs, 3px rings, 44px targets,
  non-colour cues, 68ch measure, reduced-motion parity.

Reddit API was blocked anonymously (403) during research; sentiment above is
from web-search-accessible Reddit threads, The Student Room, and provider
testimonials. No user data stored; no training use.

## What V3 deliberately does NOT copy

No Duolingo owl, no Brilliant purple, no Seneca GIF soup, no SaaS KPI wall.
No "Duolingo for GCSE". The trail metaphor + Fraunces/Inter/Plex system +
pebble geometry + subject-hue wayfinding is original to Study Desk.
